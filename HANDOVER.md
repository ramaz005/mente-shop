## 2. Как добавить товар

### Шаг 1. Загрузить фото в Supabase Storage

1. Зайди на [supabase.com](https://supabase.com) → выбери проект MENTE
2. Слева: **Storage** → папка `product-images` (или создай её)
3. Нажми **Upload** → загрузи фото (JPG или WebP, оптимально 800×1067px)
4. После загрузки нажми на файл → скопируй **Public URL** (кнопка в правом верхнем углу)

### Шаг 2. Добавить товар в таблицу

1. Слева: **Table Editor** → таблица `products`
2. Нажми **Insert row**
3. Заполни поля:

| Поле | Что вводить | Пример |
|---|---|---|
| `name` | Название товара | Топ ECLIPSE |
| `description` | Описание товара | Мягкий топ из микрофибры... |
| `price_min` | Минимальная цена | 3500 |
| `price_max` | Максимальная цена | 3500 |
| `image_url` | Public URL из Storage | https://mskd....supabase.co/storage/v1/object/public/... |
| `sizes` | Размеры | `["XS","S","M","L"]` — в точно таком формате |
| `color` | Цвет | Чёрный |
| `in_stock` | В наличии? | `true` |

4. Нажми **Save**

> ⚠️ Поле `sizes` — это массив JSON. Вводи в точном формате: `["XS","S","M","L"]`  
> Если вводишь через интерфейс и выдаёт ошибку — используй SQL:
> ```sql
> INSERT INTO products (name, price_min, price_max, image_url, sizes, color, in_stock)
> VALUES ('Топ ECLIPSE', 3500, 3500, 'https://...', ARRAY['XS','S','M','L'], 'Чёрный', true);
> ```

## 3. Панель управления заказами

Открой браузер и перейди по ссылке: **[ваш-сайт].vercel.app/admin**

### Вход
- Email и пароль — выдаст разработчик (Mara)
- Сессия сохраняется до закрытия браузера

### Что можно делать
- Видеть все заказы: имя, телефон, email, состав, сумма
- Фильтровать по статусу: Все / Новые / Подтверждены / Отправлены / Готово / Отменены
- Менять статус заказа — выпадающий список в столбце «Статус»

### Статусы заказов

| Статус | Цвет | Когда использовать |
|---|---|---|
| Новый | Жёлтый | Заказ только поступил |
| Подтверждён | Синий | Созвонились, подтвердили |
| Отправлен | Фиолетовый | Передан в доставку |
| Выполнен | Зелёный | Клиент получил |
| Отменён | Красный | Отменили |

## 4. Telegram-уведомления о заказах

Когда клиент оформляет заказ — ты получишь сообщение в Telegram с именем, телефоном и составом заказа.

### Настройка (один раз)

#### Шаг 1. Создай бота

1. Открой Telegram → найди **@BotFather**
2. Напиши: `/newbot`
3. Придумай имя бота: например, `MENTE Shop Bot`
4. Придумай username: например, `mente_shop_bot`
5. BotFather ответит токеном вида: `123456789:ABC-def...`
6. Скопируй этот токен — это `VITE_TG_BOT_TOKEN`

#### Шаг 2. Узнай свой Chat ID

1. Найди в Telegram бота **@userinfobot**
2. Напиши ему что угодно
3. Он ответит твоим числом — ID (например: `987654321`)
4. Это твой `VITE_TG_CHAT_ID`

#### Шаг 3. Добавь токены в Vercel

1. Зайди на [vercel.com](https://vercel.com) → выбери проект MENTE
2. **Settings** → **Environment Variables**
3. Добавь две переменные:
   - `VITE_TG_BOT_TOKEN` = твой токен бота
   - `VITE_TG_CHAT_ID` = твой числовой ID
4. Нажми **Save** → перейди в **Deployments** → нажми **Redeploy**

#### Шаг 4. Напиши боту сначала

Открой своего бота в Telegram и нажми `/start` — это нужно один раз, чтобы бот мог слать тебе сообщения.

#### Проверка

Оформи тестовый заказ на сайте — должно прийти сообщение в Telegram.

## 5. Подключение домена

### Если домен куплен на RU-CENTER, REG.RU или Beget

1. Зайди на [vercel.com](https://vercel.com) → проект MENTE
2. **Settings** → **Domains** → введи домен, например `mente-shop.ru`
3. Vercel покажет DNS-записи (два варианта: A-запись или CNAME)
4. Зайди в панель своего регистратора домена → DNS-записи → добавь то, что показал Vercel
5. Подождать до 24 часов (обычно 10–30 минут)

### HTTPS

Vercel автоматически выдаёт SSL-сертификат (HTTPS) — делать ничего не нужно.

## 6. Юридические страницы

Страницы `/privacy` и `/offer` уже созданы, но содержат заглушки `[в скобках]`.

**Нужно заполнить:**

1. `/privacy` (Политика конфиденциальности):
   - Название магазина и URL сайта
   - ФИО или наименование ИП/ООО и ИНН
   - Срок хранения данных
   - Email для обращений

2. `/offer` (Публичная оферта):
   - ФИО ИП / наименование ООО, ИНН
   - URL сайта
   - Способы оплаты
   - Email и телефон

3. `/contacts`:
   - Email
   - Telegram username
   - Адрес самовывоза (если есть)
   - Ссылка на Instagram или VK

> ⚠️ Для заполнения юридических страниц лучше проконсультироваться с юристом или использовать готовые шаблоны для ИП/ООО.

## 7. Что делать если что-то сломалось

### Сайт не открывается
- Зайди на [vercel.com](https://vercel.com) → проверь статус деплоя
- Если красный — напиши разработчику

### Заказы не сохраняются
- Зайди на [supabase.com](https://supabase.com) → **Table Editor** → `orders`
- Если таблица пустая, но заказы были — возможно, проблема с RLS
- Напиши разработчику

### Telegram-уведомления не приходят
- Проверь, что написал боту `/start`
- Проверь переменные в Vercel: `VITE_TG_BOT_TOKEN` и `VITE_TG_CHAT_ID`
- После изменения переменных нужен Redeploy

### Нужно изменить текст или фото на сайте
- Обратись к разработчику (Mara)
